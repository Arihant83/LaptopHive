# 💻 LaptopHive

**LaptopHive** is a simple, beginner-friendly laptop shopping website built using HTML and CSS. It features a clean design with a brown-and-cream color theme with separate pages for browsing laptops, exploring brands, viewing deals, and contacting the website.

## ✨ Features

- **Home Page:** Welcome section, featured laptops, and product categories.
- **Laptops Page:** Displays laptop products with prices and specifications.
- **Brands Page:** Explore popular laptop brands.
- **Deals Page:** Showcases sample discounts and offers.
- **Contact Page:** Includes a contact form layout.
- **Responsive Design:** Adapts to different screen sizes.
- **Navigation Bar:** Easy navigation between all five pages.
- **Shared Styling:** A common CSS file maintains a consistent design.

## 🛠️ Technologies Used

- HTML5
- CSS3

LaptopHive/

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Navigate between the different pages using the navbar.

## 🎯 Project Purpose

This project was created to practice fundamental web development concepts, including HTML page structure, CSS styling, CSS Grid, Flexbox, responsive design, navigation links, and reusable stylesheets.

## ⚠️ Limitations

- Shopping cart buttons are for display only.
- The contact form does not send messages.
- Product prices and discounts are sample data.
- The website does not include a backend, database, or payment system.
